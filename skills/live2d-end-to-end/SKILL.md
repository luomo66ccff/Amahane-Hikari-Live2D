# Live2D 端到端制作

在需要从零整理或继续制作 Hikari Live2D 时使用本技能。目标是得到可编辑、可复现、可核验的源工程、运行包和网页交付；已有美术不强制重新生成，缺失结构才补候选。

先锁定角色身份、风格、参考图和允许的变更范围，再决定复用、局部补绘或生成候选。生成候选只能进入候选区；必须在 Photoshop 中验证真实 Alpha、边缘、配准、遮挡和拆层，并完成保存、重开、三底色和有限错位检查后，才允许进入 Cubism。候选生成不能被描述为一键完成。

从零项目在 Cubism 中从受控 PSD 新建；续作先核验并复用已有已验收 CMO3，只有材料或绑定确有变更时才重新导入。无论入口为何，都记录真实 ArtMesh、遮罩、绘制顺序、网格、变形器和参数 ID，并以中性态为回退点逐项绑定。头部体积要由 Head/Face 的真实局部形变和颈部补偿建立，嘴、眼、肩袖、饰品要能在组合姿态中连续。Q 弹层级可让视线、头部、身体和发饰分层跟随，手臂保持肩根到袖端的自然连接与小幅轻摆；不能用整脸缩放、整臂平移或高频同相物理替代。

进入 Cubism 编辑器源工程的里程碑时执行保存—关闭—重开—导出，并以真实 Core 读回和人工视觉检查共同验收；纸面需求和候选材料阶段只做版本化记录，不要求导出。参数名、JSON、截图或枚举到 ID 只能算线索；未绑定、未读回、未查看连续运动的项目标为待验或未验证。动作需有开始、保持、结束、复位、打断和重入，网页的口型、动作、物理和暂停必须有明确所有权。
