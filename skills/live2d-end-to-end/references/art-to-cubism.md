# 从角色需求到 Cubism

本参考描述模型制作门禁。它把本项目已经记录的经验与新项目需要重新证明的步骤分开；历史报告中的数值是线索，不是新项目的固定参数。

## 0. 需求和风格锁定

先写一页短规格：角色身份、正面中性参考、表情范围、服装范围、输出平台、可修改区域、证据要求和停止条件。以同画布、同瞳距、同裁切的对照检查身份，先看眼裂、虹膜遮挡、嘴宽、下脸节奏和左右发丝关系，再看腮红或笑弧。不要让“更萌”、更大的眼睛或对称化覆盖原有辨识度。

Hikari 本项目的锁定项是银白长发、红瞳、圆润白兽耳、呆毛和月雪主题；月霜白、冰川蓝、绯晶红，以及月环、雪花、红宝石、细链和水晶属于已确认的视觉语言。新项目若素材不同，改写锁定表，不把这组特征当作通用模板。保留原 PSD、工程和上一版可运行包，变更范围逐条登记。

## 1. 候选生成和采用

完全零素材起步时，先依据需求生成正面中性整体设定候选，选定身份和构图主参考，再把主参考拆成按遮挡/形变需要的部件清单；随后只对缺失的隐藏结构做局部生成或补绘，最后在 Photoshop 中正式拆层。整体设定图只作身份与构图参考，不成为正式 ArtMesh；生成 PNG 不等于分层 PSD，也不能冒充实际多轮生成记录。

可移植的短提示模板：

```text
角色描述：[年龄感/发色/眼色/耳朵/服装/主题]
构图：[正面中性、半身或全身、画布比例、留白]
风格锁定：[线条、配色、明暗、必须保留的非对称特征]
目标部件：[整体设定参考 / 指定发束 / 耳根 / 颈根 / 口腔 / 肩袖隐藏底]
输出约束：只生成目标内容；完整形状在画布内；透明 RGBA；无棋盘格、背景、文字或其他角色。
用途：仅作候选或隐藏结构参考；正式使用前须由 Photoshop 原生分层、补绘、配准和 Alpha QA。
```

已有美术已经满足结构需求时直接复用。缺少额头、脸侧、耳根、颈根、口腔、肩关节、袖内或发根隐藏区时，才生成或补绘局部候选。候选提示应说明“只生成指定部件、完整根和尖端都在画布内、透明 RGBA、无棋盘格、无背景和其他角色”，并保留原参考和原始输出。

候选先放版本化候选目录，按身份、画风、形状完整度、真实 Alpha、边缘、坐标配准和遮挡闭合筛选。生成工具声称透明，不能证明文件 Alpha 合格；棋盘格像素、抠白、圆形羽化补片、放大纹理或整张重生成均不能代替正式分层。候选不通过就保留失败记录并换方案，不能重复把它导入模型。

## 2. Photoshop 材料门禁

在 Photoshop 原生路径完成正式分层和补绘，至少检查：

- 文档尺寸、RGB/8-bit、目标色彩空间、透明通道、注册点和图层边界；
- 真实 Alpha 的非零支持、半透明边缘、白/黑/中灰背景上的光晕和透明区 RGB；
- 独立眼白/虹膜/眼睑、上下唇/口腔、脸颊/下颌、颈部接触影、耳根/前后发、肩袖/袖内、手腕和饰品挂点；
- 关闭各层、局部错位、展开头发/袖布、肩腕组合后，隐藏底画仍覆盖会露出的区域；
- 拆层只服务于独立遮挡或变形，不用层数宣称质量；保留原始绘制顺序、低不透明度阴影和可回退版本。

将参考层、QA 背景和弃用层从最终导入副本排除。保存、关闭、重开导入副本，再导出默认中性和三底色检查；原生合成与母版可用 Alpha/预乘口径复核，但像素统计不能代替肉眼。Photoshop QA 未通过时停止 Cubism 分支，修材料并重新验收。

## 3. Cubism 导入、遮罩和网格

从通过门禁的受控 PSD 新建模型，记录实际 ArtMesh ID、Opacity、DrawOrder、纹理和 Parts；从零制作时不要打开旧模型来继承未知绑定树。续作可以复用已有 CMO3，但前提是来源、版本、对象关系、已知绑定和回退点都有记录，并先独立读回。按实际对象逐项恢复 clipping/mask，保存、关闭、重开后再次读取。初始自动网格只提供起点；眼睑、嘴、细发、袖布和关节按动作需要加密或手动整理。

可用下列层级作为起点，再按当前模型对象调整：

```text
Body_Root (BodyZ)
└─ Body_XY
   ├─ Torso_Root (呼吸、胸腰和连续裙体)
   │  ├─ Collar_Base / Neck_BodyAnchor
   │  └─ Arm_Base_L/R → Shoulder → Sleeve_Root/Mid/Tip → Wrist_Connection
   └─ Head_Root (HeadZ)
      ├─ Neck_Connection
      ├─ Hair_Back / HeadAccessory_Base
      └─ Head_XY
         └─ Face_XY → Eyes / Brows / Mouth / FrontHair / Ears
```

PSD 组不是 Cubism 变形器树。Body 只在公共父级绑定一次，HeadXYZ 在身体姿态上追加，颈部和下颌只做必要补偿。先做中性、端点和中间/斜向插值，再做 Head/Body 反向组合；眼睛、虹膜、上下眼睑和口腔要在脸部遮罩内保持关系。

## 4. 关键形、嘴部、肩部和物理

从实际枚举的参数范围开始，不把 `ParamAngleX` 的数值直接当角度。标准参数可作兼容入口；自定义参数只有在实际关键形、导出和读回都成立时才采用。建议逐层验证：

1. Head X/Y/Z 与 Body X/Y/Z：看近远侧眼形、鼻口位置、脸侧/下颌、耳根、头发、颈根和领圈，而不是整头平移或缩放。
2. 嘴部（仅当需求包含这些表演时）：闭口轻笑、小幅开合、圆口、抿嘴、左右鼓脸、闭口轻咀嚼；咀嚼由下颌、嘴角和脸颊协同，保持口腔遮罩。
3. 肩颈手臂：左右单肩、双肩缩起和歪头组合。肩根、颈部、领口、袖根、上臂、腕底要连续；不平移整条手臂、不缩短脖子、不改手臂长度。
4. Q 弹和次级物理：局部躯干 Warp 可产生轻微压缩/舒展，下游臂部 Rotation 负责整臂随肩。发束、耳朵、呆毛、袖布、尾带、链和水晶按挂点拆开，根部稳定、末端滞后，幅度从小到大调；不让所有输出同相抖动。
5. 表情和动作：好奇（视线先到、头稍后跟随、轻歪耳动）、害羞（偏视、肩收、嘴角变化后回看）、得意（单侧嘴角、轻抬下巴、克制耳/呆毛回应）。每段都有开始、保持、结束、恢复，并支持打断和重入。

每个关键形都回到中性重新选择对象并读回，避免失败点编辑造成双重位移。保存递增 CMO3；若编辑器无法可靠保存或导出，保留错误证据，给出精确人工接管清单并将绑定标为 BLOCKED。

## 5. 导出门

保存、关闭、重开后再导出 `model3.json`、MOC3、CDI、纹理、physics、表情和 motion。对导出物检查引用存在、参数/Drawable/Part 可读、拓扑/UV/绘制顺序/物理/表情与未改状态符合预期。截图或 JSON 名称不能伪造 CMO3/MOC3，也不能弥补缺少的网格和关键形。

本项目的实际经验是：Photoshop 材料门禁通过后，仍要逐步完成原生导入、遮罩、网格、保存重开和运行时读回；早期导入基线只代表未绑定模型，不能被扩写成完整交付。下一项目应从自己的当前工程重新执行这些门禁。
